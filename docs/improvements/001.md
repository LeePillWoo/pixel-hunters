# 픽셀헌터스 개선사항 #001

2026-11-16 | 1차 개선 요청사항 (원문 그대로)

## 1. 윈도우 데스크톱 연동
- 태스크바 상시 표시: Taskbar Hero처럼 윈도우 화면 하단에 게임이 상시 표시되도록 구현.
- 숨기기/표시 토글: 버튼 하나로 게임 화면을 숨기거나 다시 표시할 수 있도록 구현.
- 백그라운드 자동 진행: 게임 화면을 숨기거나 다른 작업을 하는 중에도 전투, 채집, 머지 등 모든 시스템이 정상 작동하도록 구현.

## 2. 자동 머지 시스템
- 주기적 자동 합성: 설정된 시간 간격마다 아이템 자동 합성.
- 쿨타임 강화: 골드를 사용해 자동 머지 주기를 단축.
- 자동 머지 관련 능력치를 별도 강화 항목으로 관리.

## 3. 캐릭터 RPG 스탯 시스템
| 스탯 | 기능 |
|---|---|
| 힘(STR) | 공격력 증가 |
| 체력(HP) | 최대 생명력 증가 |
| 방어력(DEF) | 받는 피해 감소 |
| 크리티컬 확률 | 치명타 발생 확률 증가 |
| 크리티컬 데미지 | 치명타 피해량 증가 |
| 공격속도 | 공격 간격 단축 |

- 각 스탯을 골드로 강화할 수 있도록 구현.
- 강화 단계에 따라 능력치 증가.
- 캐릭터 성장에 따라 전투력이 높아지는 구조.

## 4. 시스템 강화 및 재화
| 강화 항목 | 강화 효과 |
|---|---|
| 자동 머지 속도 | 자동 합성 쿨타임 감소 |
| 채집 속도 | 자원 획득 주기 단축 |
| 전투 자동화 | 자동 전투 효율 개선 |
| 골드 획득량 | 획득 골드 증가 |
| 아이템 획득률 | 아이템 드롭 확률 증가 |

재화 정책
- 현재는 모든 강화 비용을 골드로 통일.
- 전투, 채집 등 플레이를 통해 골드 획득.
- 향후 별도 강화 포인트나 특수 재화 추가 가능하도록 확장성 고려.

## 5. 스테이지 및 보스 확장
- 기존보다 스테이지 수 확대.
- 스테이지별 보스 몬스터 추가.
- 스테이지 진행에 따른 적 능력치 및 난이도 증가.
- 이미지는 추후 교체 예정이므로 현재는 임시 이미지 사용.
- 몬스터와 보스 이미지 교체가 쉽도록 데이터와 이미지 리소스 분리.

## 6. 캐릭터 전직 시스템
- 캐릭터 성장에 따른 전직 기능 추가.
- 특정 레벨 또는 조건 달성 시 전직 가능.
- 전직에 따라 능력치 및 전투 특성 변화.
- 추후 다양한 직업과 상위 전직으로 확장할 수 있는 구조 설계.

## 7. 해상도 및 UI 개선
- 낮은 해상도에서도 주요 글자와 수치가 읽히도록 개선.
- 자동 대응되지 않는 해상도에서도 UI 요소가 잘리거나 겹치지 않도록 레이아웃 재설계.
- 게임 화면 크기에 따라 글자 크기, 버튼 및 패널 배치 최적화.
- 특히 화면 하단에 작게 표시되는 환경에서 가독성 확보.
