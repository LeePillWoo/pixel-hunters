# 🎮 게임 개발 명세서 (GDD): 픽셀 헌터스

**장르:** 2D 방치형 횡스크롤 타워 크롤러 + 머지(Merge) 크래프팅 RPG  
**플랫폼:** 웹(HTML5), 모바일 호환  
**핵심 컨셉:** 방치형의 편리함, 머지의 쾌감, 몬스터헌터의 로망(부위 파괴, 소재 파밍, 장비 제작) 결합

---

## 1. UI 레이아웃 구조 (3분할 화면)

개발 시 화면을 크게 3가지 영역으로 나누어 구성합니다.

1. **[좌측 영역] 타워(무한의 탑) & 주둔지**
   * **최상단:** 현재 등반 중인 최전선 층(예: F10 보스룸)의 전투 진행 상태.
   * **중간 리스트 (주둔지):** 클리어 완료된 하위 층(F1~F9). 각 층마다 '파견된 동료'가 보이며, 파밍 진행 바가 1초마다 차오릅니다.
   * **파밍 연출:** 게이지가 찰 때마다 아이템 아이콘이 팝업되어 우측 인벤토리로 날아가는 효과.
   
2. **[우측 상단 영역] 보스 전투 뷰**
   * **중앙:** 보스 몬스터와 거대한 HP 바.
   * **좌측:** 공격 모션을 취하는 헌터 캐릭터.
   * **우측 하단:** 무작위 주기로 1.5초간 팝업되는 **[부위 파괴 (Break!)] 버튼**.

3. **[우측 하단 영역] 머지(Merge) 인벤토리**
   * **그리드:** 5x4 크기의 인벤토리 슬롯.
   * **기능:** 좌측 타워에서 채집된 1티어 아이템이 빈 슬롯에 자동 추가되며, 유저가 직접 드래그 앤 드롭으로 아이템을 합칩니다.

## 2. 층별 등반 & 방치형 캠프 (Tower UI)

![베이스 캠프 화면](camp.jpg)
*(위 이미지: 층별로 동료들이 배치되어 자원을 캐는 무한의 탑 단면)*

* **생태계 정복:** 1~10층(숲), 11~20층(사막/광산), 21~30층(화산) 등 테마별로 구성됩니다.
* **주둔 및 자동 파밍 (Idle):** 정복이 완료된 층에 퀘스트로 얻은 '동료 헌터'나 '수인족'을 배치합니다. 
* **자원 생산:** 배치된 동료는 1초마다 해당 층 고유의 하위 소재(예: 숲-약초, 광산-철광석)를 생산하여 머지 인벤토리로 보냅니다.
* **오프라인 보상:** 게임을 껐다 켜면 `(현재 시간 - 마지막 접속 시간) * 층별 생산량`을 계산하여 재접속 시 일괄 지급합니다.

## 3. 보스 전투 & 부위 파괴 기믹 (Combat)

![보스 전투 화면](boss.jpg)
*(위 이미지: 드래곤 보스와의 전투 및 부위 파괴 팝업 UI)*

* **자동 전투:** 메인 헌터는 자동으로 일정 주기로 보스를 공격하여 HP를 깎습니다.
* **부위 파괴 (Break Part) 팝업:** 전투 중 무작위 타이밍(예: 5~10초 간격)에 화면에 **'BREAK PART'** 버튼이 1.5~2초간 짧게 나타납니다.
* **성공 보상 (수동 개입의 핵심):** 유저가 타이밍에 맞춰 버튼을 클릭하면 다음과 같은 효과가 발생합니다.
  1. 보스에게 크리티컬 데미지 및 일시 스턴.
  2. 머지(Merge)로는 절대 얻을 수 없는 **'보스 고유 희귀 소재(뿔, 역린, 꼬리 등)'** 확정 드랍.

## 4. 머지 (Merge) 기반 인벤토리

![머지 인벤토리 UI](merge.jpg)
*(위 이미지: 동일한 소재를 드래그하여 상위 티어로 합치는 머지 인벤토리)*

* **소재 압축 로직:** 방치형 파밍으로 쏟아지는 하위 소재를 플레이어가 직접 드래그 앤 드롭으로 합칩니다. (원클릭 일괄 강화가 아닌 '손맛' 강조)
* **진화 방식:** 동일한 1티어 아이템(예: 하위 뼈) 2개를 겹치면, 2티어 아이템(상위 뼈) 1개로 변환됩니다.
* **시크릿 융합 (도감 요소):** 서로 다른 특정 소재(예: 철광석 + 불꽃 주머니)를 합치면 특수 합금(홍련석)이 탄생하는 퍼즐 요소가 존재합니다.

## 5. 장비 크래프팅 및 특성 트리

유저는 '머지로 압축한 최고 티어 베이스 소재'와 '보스 부위 파괴로 얻은 희귀 소재'를 결합해 무기를 제작합니다.

| 무기 종류 (Weapon) | 전투 스타일 및 패시브 특성 | 필요 핵심 소재 |
| :--- | :--- | :--- |
| **대검 (Greatsword)** | 공격 속도는 50% 느리지만 한방 데미지가 매우 강력함. 보스 공격 캔슬(경직) 확률 15%. | [티어3 뼈] x5 + [보스 갑각] x1 |
| **쌍검 (Dual Blades)** | 공격 속도 200% 증가. 빠른 연타로 크리티컬 확률이 높으며 화상/중독 속성 누적. | [티어3 가죽] x5 + [보스 발톱] x1 |
| **해머 (Hammer)** | 묵직한 타격 피해. 적의 기절 게이지를 쌓아 '부위 파괴' 버튼 유지 시간을 1.5초에서 3초로 연장. | [티어3 광석] x5 + [보스 뿔] x1 |
